# 雲端版更新紀錄

## v1.0.0 — 首個正式版本基準

發布狀態：準備中。版本號已確定；正式站採用方式尚待使用者指定，尚未據此合併 main、切換 GitHub Pages 或發布 GitHub 正式 Release。

### 功能範圍

- Cloudflare Worker + D1 雲端同步、學生 PIN 與管理者登入、角色權限及 CORS。
- 管理單字與課次、指定課次重置、各課各階段獨立解鎖開關。
- 六個學習階段；Miss／miss 聽音辨字合併；英文字母及單字優先採用美式 en-US 語音。
- 含空格片語、空格字塊、固定空格填字、終極默寫空格／撇號／連字號鍵。
- 舊版備份驗證與一次性匯入、雲端備份匯出、原瀏覽器本機資料保留。
- 登入畫面、管理頁、頁尾與 health 顯示版本，方便查驗部署。

### 發布前仍需確認

- 正式站網址與資料庫承接方式；目前 staging 已有學習進度，禁止覆蓋。
- 真實備份匯入比對、隔離復原演練及實體裝置操作／發音驗收。
- PR 是否合併及正式發布方式需依使用者的切換指示辦理。

## 後續版本編號

- v1.0.1、v1.0.2：修正問題，不改變主要功能。
- v1.1.0、v1.2.0：新增相容功能。
- v2.0.0：不相容變更，需另列資料遷移及回復步驟。

每次發布記錄版本、日期、功能變更、實際測試結果、部署版本與資料相容性；未執行的驗收維持待驗收。
