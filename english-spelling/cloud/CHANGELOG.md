# 雲端版更新紀錄

## v1.0.0 — 首個正式版本基準

正式發布基準：2026-10-21。依使用者指示採兩站並行，後續修改以測試站為主，正式版由獨立發布流程更新。部署結果、版本與實際驗證見本版本 GitHub Release 及 TEST_REPORT.md。

- 正式站：https://ian-spelling.pages.dev/
- 測試站：https://ian-spelling-staging.pages.dev/
- 不同 Worker、D1、Secrets、CORS；session token 綁定對應前端來源。預設 deploy／migrate 只操作 staging，正式部署使用明確的 production 指令。
- 正式站以測試站在 2026-10-21 08:44:28（Asia/Taipei）的一致性備份建立：10 課、82 字、8 筆作答。完整 schema、資料、sequence 與外鍵已經本機及獨立正式 D1 復原比對通過；後續兩站資料各自獨立。

### 功能範圍

- Cloudflare Worker + D1 雲端同步、學生 PIN 與管理者登入、角色權限及 CORS。
- 管理單字與課次、指定課次重置、各課各階段獨立解鎖開關。
- 六個學習階段；Miss／miss 聽音辨字合併；英文字母及單字優先採用美式 en-US 語音。
- 含空格片語、空格字塊、固定空格填字、終極默寫空格／撇號／連字號鍵。
- 舊版備份驗證與一次性匯入、雲端備份匯出、原瀏覽器本機資料保留。
- 登入畫面、管理頁、頁尾與 health 顯示版本，方便查驗部署。

### 保留的待驗收項目

- 實體裝置操作、語音音色與兩台真人裝置同步仍待使用者配合，未標為通過。
- 原瀏覽器的舊版 3 課 JSON 不覆蓋目前 10 課的雲端學習資料；其原檔仍保留，舊 JSON 的獨立匯入演練尚未執行。
- 原 GitHub Pages 來源仍為 main /，PR 保持 open；兩站並行不需變更該來源。
